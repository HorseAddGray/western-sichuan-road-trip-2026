# 景点新增链接设计

## 目标

将备忘录「景点」分类的新增入口改为「新增链接」，让用户粘贴小红书分享文本后，把解析出的文章标题和链接追加到所选景点的参考文献中。

## 交互

- 当前分类为「景点」时，标题右侧按钮显示「新增链接」，表单标题同名。
- 表单包含「归属景点」下拉框和「小红书分享内容」文本框；景点选项来自现有景点子类别。
- 提交时取分享文本中的第一个 `http(s)` URL，标题取该 URL 前的最后一个非空文本片段；无法提取标题或 URL 时保留表单并提示对应字段。
- 成功后链接追加到目标景点现有 `links` 数组末尾，继续由现有拖动功能排序并通过 `todos` 集合共享同步。
- 非景点分类继续使用既有「新增信息」表单，避免改变健康、厕所与美食录入。

## 数据与验证

不引入新数据结构。景点仍使用 `{ title, url }` 链接项，修改目标景点 todo 后调用既有共享保存流程。测试覆盖入口标记、解析辅助函数、景点选择和 links 追加路径。
