# 每日行程备注、景点评价与备忘录联动

## 目标

让每日时间线在相邻节点之间记录行程安排、趣事、美食和游玩心得；让抵达且已收录到备忘录“景点”中的地点可被双人评价，并能直接打开对应的景点参考资料。

## 交互与界面

- 每个相邻行程节点的间隔下方显示“行程安排 / 备注”区域；没有记录时显示添加入口，有记录时显示按添加顺序排列的文字卡片。
- 备注支持新增、编辑、删除；内容为空时不保存。
- 抵达已匹配备忘录景点的节点显示 `⭐`，地点名称是按钮。点击后切换到备忘录的“景点”类别，展开、平滑滚动并高亮匹配的景点名称。
- 评分位于该抵达景点节点最右侧，分为“马甲”和“仔仔”两组。每组初始显示空白虚线圆圈；点击圆圈弹出“绿色圆勾 / 红色圆叉”二选一；保存后仅显示所选的一种圆形标记。再次选择会覆盖原评分；可清除恢复为空白圆圈。
- 未被备忘录景点收录的节点没有星标、跳转或评分，避免把出发、休整、餐饮等普通节点误当作景点。

## 数据与同步

- 行程记录以稳定的 `day + schedule item id/index` 键保存；备注记录含独立 id、内容与创建时间，评分记录含马甲与仔仔的三态值（空、勾、叉）。
- 将这些运行时数据存入现有行程运行时存储，并将其加入 D1 的共享集合配置，使本地与共享模式都可恢复且跨设备同步。
- 现有“确认行程”仍保持其已确认时间；新备注与评分不会改变完成状态。
- 以明确的景点名/别名匹配备忘录“景点”折叠项，例如“甘孜县城”匹配“甘孜县”；匹配不到时安全降级为普通文本。

## 内容变更

- 从备忘录“景点 → 甘孜县”删除现有第一篇原始网页链接，保留之后的短链参考文章。

## 验收与测试

- 数据测试覆盖：备注与评分的键、三态评分、星标/景点匹配、甘孜县首条删除。
- 运行时存储测试覆盖：行程数据本地持久化及 D1 共享集合读写。
- 页面测试覆盖：节点间备注入口、评分控件与备忘录跳转高亮标记。
- 通过既有页面数据测试、运行时存储测试、语法检查、轻量校验与差异空白检查后发布，并从线上读取验证甘孜县参考文章已更新。
