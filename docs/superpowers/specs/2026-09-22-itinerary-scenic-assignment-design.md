# 每日行程关联景点设计

## 目标

让任一每日行程时间节点可关联备忘录「景点」类别中的一个景点，并在后续点击该节点标题时定位到对应的备忘录景点。

## 交互

- 桌面端在行程节点标题上右键，移动端长按标题，打开「关联景点」菜单。
- 菜单列出备忘录景点分组，单选一个景点；可重新选择，亦可清除关联。
- 已关联的节点标题前显示 `⭐`，未关联节点保持原样。
- 点击已关联的节点标题时，切换到备忘录的景点类别、展开对应景点、滚动至该景点并短暂高亮。

## 数据与边界

- 关联关系按既有的每日行程完成键保存到 `itineraryState`，只保存一个景点分组名称。
- 不复制景点文章或更改备忘录景点数据；若景点被改名或删除，节点仍可重新关联或清除。
- 待办确认、地图按钮、评分和旅途心情继续按既有逻辑工作。

## 验证

- 自动测试覆盖关联状态、菜单入口、星标和跳转调用。
- 浏览器测试验证右键选择、标题星标、跳转后的目标展开与高亮。
