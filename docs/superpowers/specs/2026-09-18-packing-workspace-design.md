# 行囊工作区设计

## 目标

将现有行囊清单扩展为三个独立页签：行囊明细、采购清单、检查行囊。

## 行囊明细

- 展示五个大箱包；点选大箱包后展示其物品与内置收纳包。
- 洗护箱默认包含护肤包、化妆包、洗漱包；电子背包默认包含相机包。用户可新增、改名或删除收纳包。
- 每件物品包含归属标签：马甲、仔仔、共同、待分配；支持多选标签筛选。
- 物品可移动至大箱包、内置收纳包或待分配。

## 采购清单

- 新采购项先记录名称、数量和是否一次性用品。
- 点击“提交到行囊明细”后，采购项成为行囊物品，初始标签和位置均为待分配；原采购项从采购列表移除。

## 一次性用品

- 物品有 `usesTotal` 和 `usesRemaining`；每次点击“使用一次”使剩余次数减一。
- 剩余次数为零时显示“已用尽”，物品灰色划线；非一次性用品没有此控制。

## 检查行囊

- 点击“开始检查”将所有行囊物品标为未检查。
- 按当前物品顺序逐件展示；每次点击“确认无误”进入下一件。
- 全部确认后显示“检查已完成”。检查状态不改变物品是否已准备完成。

## 本地数据

箱包结构、物品归属、位置、采购清单、检查状态和一次性用品次数均储存在当前浏览器。原有物品继承现有大箱包，并以“待分配”为初始标签；不会删除既有行囊物品。
