# 旅行前准备分类切换

## 目标

保留现有“旅行前准备”的单卡片展示与本地保存方式，让用户在“注意事项”和“行囊清单”之间切换，分别查看和管理对应项目。

## 交互

- 标题下方提供两个分类切换按钮：注意事项、行囊清单。
- 当前选中的分类决定清单内容、完成进度和新增项目的归属。
- 新增项目时可选择注意事项或行囊清单；默认使用当前查看的分类。
- 每条项目支持编辑文字、勾选完成和删除。
- 默认展示注意事项；高反适应、取还车、住宿待定等已有提醒归入此分类。
- 行囊清单初始为空，等待用户自行添加。

## 数据与持久化

- 沿用现有本地 Todo 存储，不新增远端服务或同步能力。
- 每条 Todo 增加 `category`，值为 `notice` 或 `packing`。
- 旧数据没有分类时，按注意事项处理，保证已有项目仍会显示。
- 两个分类各自计算完成进度。

## 范围

- 只调整旅行前准备模块的 HTML、样式、运行逻辑及初始旅行数据。
- 不更改航班、地图、行程、租车、记账或 Cloudflare 配置。

## 验收

- 可切换两个分类，且只显示所选分类项目。
- 新增、编辑、勾选、删除后立即更新当前分类与进度。
- 刷新页面后，两个分类的项目和完成状态保持不变。
- 未分类的旧项目可正常显示在注意事项中。
