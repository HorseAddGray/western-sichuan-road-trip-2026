# 行囊与注意事项行布局调整

## 目标

让折叠箭头紧贴分类标题，让每条物品的更多操作按钮留在行项目边框内，并让桌面宽度下的新增物品输入项保持同一行。

## 结构与样式

- 行囊明细的分类标题与注意事项的所有子分类共用同一顺序：分类名称、折叠箭头、完成/条目数。
- 折叠箭头仍由现有按钮控制，不改变展开状态、键盘语义或筛选逻辑。
- 物品行继续使用现有两列布局；右侧 `•••` 所在操作区设置为条目自身的内边距范围，避免溢出到边框外。
- 新增物品表单在常规宽度下采用六列：类别、归属、标签、数量、物品名称、添加。移动端保留现有自动换行规则。

## 验证

- 新增静态回归断言，锁定两类折叠标题的 DOM 顺序、更多操作区和同排表单选择器。
- 运行行囊页面测试、运行时存储测试与生成校验。
- 在公开页检查更新后的静态资源版本。
