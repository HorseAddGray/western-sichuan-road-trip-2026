# 备忘录位置归档与精确跳转设计

## 目标

让带星标的每日行程标题跳转后稳定停留在对应备忘录景点；让美食和景点文章都按「归属景点」位置归档、管理和排序。

## 交互

- 点击带 `⭐` 的行程标题后，切换到备忘录景点类别，展开目标景点，并在浏览器完成锚点导航后将目标滚动到可视区域中央并高亮。
- 景点与美食都显示新增链接表单：选择已有归属景点，或选择「新增景点」后填写新名称；粘贴分享内容自动解析文章标题与链接。
- 美食文章按归属景点分组展示，而不是按美食名称分组；每篇文章可拖动排序，并可在桌面右键、移动端长按后加精或删除，点击页面其他位置关闭菜单。
- 所有备忘录类别通过「管理子类别排序」入口拖动调整分组顺序，排序立即用于卡片展示并保存。

## 数据与边界

- 美食文章仍归属备忘录美食类别，但其 `group` 保存景点名称；景点列表是唯一的归属位置来源。
- 现有美食文字信息保持不变；仅新增的文章链接使用位置归档。
- 不复制文章、不改变既有景点链接，且保留现有的收藏、删除和文章顺序数据。

## 验证

- 自动测试覆盖美食的景点选择入口、通用文章菜单和全部类别的子类别排序。
- 浏览器测试验证星标标题跳转后的目标在可视区域内、高亮，及美食链接按景点归档。
